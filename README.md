# База знаний Т-БКИ

Статический сайт с разделами «Судебная работа», «ПД», «Договорная работа» и «Пользователи». Раздел «ПД» содержит краткую карту процессов обработки персональных данных и ссылку на борд. В разделе «Пользователи» опубликована таблица получателей кредитных отчётов и сведений из кредитных историй по состоянию на 23 октября 2026 года. Разделы «Судебная работа» и «Договорная работа» ожидают наполнения.

## Запуск

`npm start` открывает локальный сервер на http://127.0.0.1:8000. `npm run build` создаёт статическую версию в `dist/`.

## Публикация

GitHub Actions публикует ветку `main` на https://ikhmelevskiy02-web.github.io/tbki/.
