# Ассистент поддержки Т-БКИ

Прототип внутреннего рабочего интерфейса: поиск по типовым обращениям, порядок обработки запросов, таблица сведений для получателей и подготовка черновика ответа с помощью ИИ.

## Локальный запуск

Нужен Node.js 20 или новее. Запустите из папки проекта:

```bash
npm start
```

Откройте `http://127.0.0.1:8000`. Для локального использования модели задайте `AI_API_BASE_URL`, `AI_API_KEY` и `AI_MODEL` в переменных окружения перед запуском. Пример формата есть в `.env.example`; реальный ключ в файлы проекта не добавляйте.

## Настройка совместимого API

Сервер ожидает OpenAI-compatible endpoint Chat Completions. Укажите в настройках хостинга:

- `AI_API_BASE_URL` — адрес API до версии, например `https://provider.example/v1`;
- `AI_API_KEY` — секретный ключ провайдера;
- `AI_MODEL` — точное имя модели, доступное по этому ключу.

Вызов ИИ проходит через серверный обработчик `/api/assistant`. Ключ не передаётся браузеру. Интерфейс выбирает не более трёх подходящих сценариев; сервер ограничивает размер текста и ответа. Вопрос и выбранные фрагменты базы передаются указанному провайдеру. Условия обработки и хранения данных зависят от провайдера.

В форме показано предупреждение: не вводить ФИО, паспортные данные, контакты и сведения из кредитных историй. Сервер дополнительно блокирует некоторые распространённые форматы идентификаторов, но эта проверка не гарантирует обнаружение всех персональных данных.

## Состав проекта

- `index.html`, `styles.css`, `app.js` — интерфейс, поиск по кейсам и запрос черновика;
- `worker-template.mjs`, `build.mjs` — серверный обработчик и сборка страницы в Worker;
- `dev.mjs` — локальный адаптер для запуска Worker на Node.js;
- `.env.example` — названия необходимых переменных без секретных значений.

## Сценарии прототипа

- Поиск по шести рабочим сценариям и открытие карточки с исходным вопросом и ответом.
- Подготовка ИИ-черновика с подбором до трёх релевантных материалов.
- Разделы по обработке обращений и составу сведений для получателей.
- Адаптивный интерфейс для телефона.

ИИ создаёт только черновик. Он может ошибаться и не заменяет сверку фактов, полномочий и актуального правового основания. Не используйте ответы автоматически и не отправляйте их без проверки сотрудником.

## Источник и статус наполнения

Демо подготовлено по предоставленной рабочей базе Т-БКИ. Тексты кейсов, отдельные правовые формулировки и таблица полномочий требуют проверки владельцем процесса перед применением. Репозиторий и сайт должны оставаться закрытыми для посторонних пользователей.

## Корпоративный шрифт

Стили настроены на `T Sans` / `Tinkoff Sans`. Файл шрифта не входил в материалы, поэтому используется системный запасной шрифт. Если есть разрешённый для веб-использования файл, положите его в `assets/fonts/T-Sans.woff2`.
