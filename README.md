# База знаний Т-БКИ

Статический сайт с разделами «Судебная работа», «ПД», «Договорная работа» и «Пользователи». Материалы разделов пока не опубликованы.

## Запуск

`npm start` открывает локальный сервер на http://127.0.0.1:8000. `npm run build` создаёт статическую версию в `dist/`.

## Публикация

GitHub Actions публикует ветку `main` на https://ikhmelevskiy02-web.github.io/tbki/.
