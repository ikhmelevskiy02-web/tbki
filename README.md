# Ассистент поддержки Т-БКИ

Статический прототип закрытого внутреннего интерфейса для поиска по базе типовых ответов, порядка обработки обращений и таблице о составе сведений для разных получателей.

## Запустить локально

Откройте `index.html` в браузере или запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Что работает в прототипе

- Поиск по шести сценариям и быстрый переход к карточке.
- Просмотр ситуации и текста ответа с копированием.
- Раздел с порядком обработки обращений: обращение, запрос кредитного отчёта, оспаривание.
- Фильтр таблицы получателей и состава сведений.
- Адаптивная раскладка для телефона.

Поиск и ответы работают в браузере на локальных данных из `app.js`. Подключения к клиентским системам, внешним ИИ-сервисам и отправки ответов нет. Не добавляйте сюда персональные данные субъектов или сведения о конкретных кредитных историях.

## Источник и статус наполнения

Демо подготовлено по предоставленной рабочей базе Т-БКИ. Тексты кейсов, отдельные правовые формулировки и таблица полномочий требуют проверки владельцем процесса перед применением. Вопросы, помеченные в исходнике как требующие обсуждения, не используются для автоматических выводов.

При переносе в GitHub не размещайте внутренние материалы в публичном репозитории. Репозиторий и развёртывание должны иметь закрытый доступ, согласованный с компанией.

## Корпоративный шрифт

Стили настроены на `T Sans` / `Tinkoff Sans`. Файл шрифта не входил в материалы, поэтому пока применяется системный запасной шрифт. Если у вас есть разрешённый для веб-использования файл, положите его в `assets/fonts/T-Sans.woff2` и подключите через `@font-face` в `styles.css`.
