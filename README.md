# База знаний поддержки Т-БКИ

Статический рабочий интерфейс: типовые ответы, обработка обращений, состав предоставляемых данных и судебная работа. Генерация ответов через API удалена.

## Разделы

- Главная: поиск и переходы по рабочим задачам.
- Типовые обращения: поиск, фильтры, просмотр и копирование ответов.
- Обработка обращений: каналы, требования и последовательность действий.
- Кому какие данные: таблица получателей и оснований.
- Судебная работа: шесть раскрывающихся шагов по инструкции от 12.10.2026, ссылки на страницы и полный PDF со скриншотами.

## Запуск

Из папки проекта: `npm start`. Откройте http://127.0.0.1:8000.
`npm run build` создаёт статическую версию в `dist/`.

## Публикация

GitHub Actions публикует main на https://ikhmelevskiy02-web.github.io/tbki/.
Раздел судебной работы: https://ikhmelevskiy02-web.github.io/tbki/#court.

## Оформление

Логотип предоставлен Т-БКИ. T-Sans (400, 500, 700) загружается с официального корпоративного CDN, используемого на tbki.ru. Содержимое инструкции находится в `assets/court-guide.pdf`. Файлы шрифтов не распространяются через репозиторий.
